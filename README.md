# FlipRadar V0.2

Installierbare Android-Testversion von FlipRadar.

## Enthalten
- Deutsch und Englisch
- Deal-Analyse
- Gewinn- und ROI-Rechner
- Flip Score
- Demo Deal Finder
- Meine Flips / lokales Test-Inventar
- Profil und Spracheinstellungen

## Android APK
Die APK wird automatisch mit GitHub Actions gebaut.

Workflow: `.github/workflows/build-android-apk.yml`

Build-Ausgabe: `app-release.apk`

> Hinweis: V0.2 nutzt noch Demo-Marktdaten und keine echten Marketplace-APIs.
